Expo Lynx lets an Expo / React Native app render a Lynx mini-app from a verified local bundle. The app always has a bundled fallback, while a signed remote release can become the active version without shipping a new host binary.

	<Card title="Use a safe fallback" icon="shield-check">

	</Card>
	<Card title="Deliver remote releases" icon="cloud">

## The one rule to remember

For a managed mini-app, the host loads the newest **verified local** version immediately:

```text
confirmed remote cache → otherwise embedded baseline
```

It checks the remote channel after that first local render. A remote URL is never passed directly to `LynxView` in a production managed flow.

:::tip[Start with the local test loop]
If you are adding Expo Lynx to a host app, begin with [installation](/getting-started/installation/). If it is already installed and you are changing the Delivery mini-app, use [local development](/getting-started/local-development/).
:::
