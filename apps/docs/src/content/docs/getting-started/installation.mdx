---
title: Installation
description: Install Expo Lynx, embed a safe baseline, and create the first native runtime.
---

Expo Lynx runs in an Expo development or release build, not Expo Go. Each
managed mini-app has an embedded bundle that always works offline; remote
delivery only replaces it after verification.

## 1. Add the module and CLI

```sh
pnpm add expo-lynx-view
pnpm add -D @expo-lynx/bundle-cli
```

## 2. Describe the host app's features

Create `lynx-bundle.config.mjs` in the Expo app:

```js
export default {
  appId: 'shop',
  featuresDir: './features',
  features: { delivery: {}, orders: {} },
  embeddedOutputDir: './generated/expo-lynx/embedded',
  releaseOutputDir: './dist/lynx-releases',
};
```

`appId` is the host-app namespace in the shared Worker. Feature IDs may repeat
between different host apps.

Before replacing the example URL below, provision the shared Worker once with
[Cloudflare Worker setup](/managed-delivery/cloudflare-worker/#first-time-cloudflare-setup).

## 3. Configure the plugin and build the baseline

```json
{
  "expo": {
    "plugins": [["expo-lynx-view", {
      "embeddedBundlesPath": "./generated/expo-lynx/embedded",
      "publicKeyPath": "./keys/lynx/updates.public.pem",
      "deliveryEndpoints": {
        "delivery": "https://your-worker.workers.dev/v1/shop/delivery"
      }
    }]]
  }
}
```

```sh
pnpm lynx bundle delivery
cd your-expo-app
pnpm exec expo prebuild --platform ios
```

`lynx bundle` calculates an Expo native fingerprint and writes it into the
embedded registry. Prebuild copies that identity, endpoint map, bundles, and
public key into the iOS app.

:::note[When a new native build is needed]

Run `pnpm lynx bundle <feature>`, prebuild, and install a new app binary after
changing native inputs: an embedded baseline, native dependency, Expo plugin,
public key, or endpoint. Publishing an ordinary remote release does not need a
native rebuild.

:::

## 4. Render the managed feature

```tsx
<ExpoLynxView source={{ kind: 'managed', feature: 'delivery' }} style={{ flex: 1 }} />
```

The first launch renders the embedded baseline. Later launches synchronously
render a compatible verified cache when one exists, then check the Worker in
the background.
