---
title: Local iPhone testing
description: Test a local Worker and R2-style delivery flow on an iPhone.
---

Start the Console and local Cloudflare Worker from the monorepo root:

```sh
pnpm lynx console
```

It listens on port `8787`. For a physical phone, put your Mac's LAN address in
the Expo plugin endpoint, for example:

```text
http://192.168.1.20:8787/v1/default/delivery
```

`localhost` points to the phone, not your Mac. Phone and Mac must be on the
same Wi-Fi, and macOS firewall/VPN settings must permit the connection.

Then, in another terminal:

```sh
pnpm start
pnpm lynx release
```

Choose the uploaded bundle in the Console and enable it. A new device starts
from its embedded fallback. An enabled update downloads, verifies, and stages;
reopen the feature to use it. A force update reloads the matching feature after
the verified install.

:::caution[Internal builds only]
Plain HTTP managed delivery is permitted only for an internal Release build
compiled with `LYNX_ALLOW_LOCAL_MANAGED_RELEASE=1`. Production builds must use
the HTTPS Worker URL.
:::
